# Super-Store-Sales-Dashboard
This project is an interactive Sales Data Analysis Dashboard built using Power BI. The dashboard is designed to transform sales data into meaningful business insights by analyzing sales performance, revenue trends, product performance, and other key business metrics.

## Objective

The main objective of this project is to analyze sales data and create a user-friendly dashboard that can support data-driven business decisions. The dashboard helps understand overall sales performance, identify important trends, compare different segments, and analyze which products or categories contribute most to sales.
